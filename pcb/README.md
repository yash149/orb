# PCB source files

The current ORB prototype uses modules and breadboard wiring. No custom PCB source has been supplied.

If a custom PCB is designed, add the editable source files here. For KiCad, the supplied Fallen checklist names at least:
- `.kicad_pro`
- `.kicad_sch`
- `.kicad_pcb`
- `.kicad_prl`
- `gerbers.zip`

Do not add fabricated or placeholder design files.
